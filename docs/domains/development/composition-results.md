# Composition qualification

## Use the evidence

Read [observed.yaml](observed.yaml) for measured results, supported target shapes and remaining adapter work.
Use the [matrix](qualification-matrix.json) to locate executable assertions.
Keep the [composition assignment](composition-proof.md#acceptance) as the acceptance reference.
Treat the result as conditional suitability, not complete [product](../product/DOMAIN.md) adoption.

## Autonomous composition

Use native invocation to give each child an independent lifecycle and input.
Route commands through explicit actor connections.
Collect outputs through invocation completion before completing the parent.
Declare whether child failure stops sibling work or permits recovery.
Distinguish actor cancellation from reversal of external effects.

## Structural extension

Derive the native definition before creating actors.
Validate insertion ownership and target shape before changing the copied definition.
Reject competing claims instead of choosing an implicit overwrite order.
Keep the authored definition immutable and independently executable.
Preserve origin records when relocating an existing state under an inserted approval boundary.

## Inspection

Keep authored definition, resolved definition and execution trace as separate inspection inputs.
Identify each occurrence through its run, instance, definition revision and visit ordinal.
Keep extension-origin records beside added states and connections.
Use snapshot values to locate active resolved states.

## Graph choice

Assess topology operations separately from statechart execution and extension policy.
Use the recorded collision test before choosing union as a composition operation.
Retain explicit conflict checks when an operation resolves collisions by overwrite.
Require a demonstrated reduction in adapter code before routing this insertion through a generic graph representation.

## Gotchas

Distinguish a settled promise rejection from cancellation of active work.
Read the pinned promise implementation before asserting cancellation-signal behavior after settlement.
