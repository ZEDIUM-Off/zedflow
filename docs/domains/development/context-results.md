# Context qualification

## Use the evidence

Read [observed.yaml](observed.yaml) for measured results, comparison methods, host policies and remaining gaps.
Use the [matrix](qualification-matrix.json) to locate each executable assertion.
Keep this evidence separate from complete [product](../product/DOMAIN.md) adoption.
Run the native package check before extending these boundaries.

## Context boundary

Keep raw history separate from the model projection.
Apply request preparation before context transformation and model conversion.
Require explicit conversion for custom host messages.
Copy model-facing values before provider adaptation.
Keep source identity and transformation provenance beside the projected messages.
Inspect resource access separately from model exposure.

## Compaction boundary

Let the machine select whether compaction is needed and when a completed summary can become a checkpoint.
Keep the previous summary, summarized history and split-turn prefix available to the summary adapter.
Reject incomplete output and stale transcript revisions before installation.
Preserve raw entries for inspection after installing the checkpoint.
Treat an in-memory checkpoint as distinct from durable session recovery.

## Extension boundary

Run finite input and before-run hook chains before invoking the native loop.
Keep tool admission and result replacement at their existing loop boundaries.
Record hook failures according to the phase policy instead of hiding them.
Invalidate old resource scopes when replacing a session.
Suppress late events from the replaced loop and release only owned resources.

## Comparison boundary

Distinguish direct oracle comparisons from native tests based on source-derived expectations.
Treat simulated provider hooks as adapter evidence, not proof of transport support.
Keep unresolved summary and recovery behavior visible in the observations.
Qualify resource rebinding and recovery settlement in the continuity lot.
Seek explicit provider authorization before evaluating real summarization quality or transport behavior.

## Gotchas

Preserve the normalized transcript type when copying messages for provider adaptation.
Inspect system-message replay semantics before treating a later instruction as a replacement.
Resolve the failure details through the context observations.
