# Zedflow product intent

## Purpose

Zedflow is a standalone, graph-native coding-agent harness. It is not a fork-maintenance project and does not track any external Rust agent repo as an upstream.

## Canonical reference baseline

- `langgraph v1.2.6`: https://github.com/langchain-ai/langgraph/tree/1.2.6

## What Zedflow is

- A modular coding-agent harness.
- A graph-and-flow oriented runtime for plug-and-play orchestration units.
- A local-first product with explicit tools, sessions, config, and runtime boundaries.

## What Zedflow is not

- Not Pi Rust.
- Not a drop-in Pi replacement.
- Not a compatibility or parity ledger for another Rust agent repo.

## Near-term product direction

- public identity: Zedflow
- orchestration reference: `langgraph v1.2.6`
- ambition: a modular harness with plug-and-play graphs and flows that make coding-agent behavior inspectable and composable
